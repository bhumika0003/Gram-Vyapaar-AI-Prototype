# Gram Vyapaar AI Prototype
**Public service prototype for Bharat.**

Gram Vyapaar aids entrepreneurs from rural areas in validating a business concept, getting knowledge about financing, and having a personalized action plan for their village.

## Main Features
* **Geo + RAG Advisory Module:** Local business viability assessment via geographic intelligence and documents retrieval.
* **Competitor Mapping:** Business signal visualization near you and the calculation of your market reach.
* **Risk Transparency:** Honest five-dimension risk assessment with manual verification states.
* **Strategic Pivots Suggestions:** Alternative solutions (fixed routes, coop fallbacks) if the concept is considered too risky.

## Status Quo
It’s a frontend prototype that shows user flow. Currently running in demo-safe mode with zero external API calls until the integration of the live backend happens
